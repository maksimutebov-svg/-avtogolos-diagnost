# # АвтоГолос — интеллектуальная голосовая система диагностики автомобиля
## Назначение
Система считывает телеметрию с OBD-II, анализирует данные и выдаёт голосовые команды водителю.
Разрабатываемое решение представляет собой программно-аппаратный комплекс для интеллектуальной голосовой диагностики технического состояния автомобиля. Система подключается к стандартному диагностическому разъёму OBD-II (On-Board Diagnostics) транспортного средства, считывает телеметрические данные с бортовых систем автомобиля, анализирует их в реальном времени и выводит результаты в виде голосовых сообщений через встроенный динамик.
Основная идея проекта — предоставить водителю максимально простой и безопасный способ контроля состояния автомобиля без необходимости отвлекаться от дороги на чтение показаний с экрана или понимание сложных технических терминов.   

## Состав решения
- Arduino UNO R3
- Bluetooth-модуль HC-05
- MP3-плеер DFPlayer Mini
- SD-модуль
- OBD-II адаптер ELM327

## Требования к окружению
- Arduino IDE v2.x
- Библиотеки: SoftwareSerial, SPI, SD, DFRobotDFPlayerMini

## Порядок сборки и запуска
1. Подключить компоненты по схеме. HC 05 в режим Мастер
2. Загрузить скетч в Arduino.
3. Подать питание.
4. Система автоматически подключится к OBD-II и начнёт диагностику.

  ## Риски и ограничения.
  
Риски: Неточность датчиков — данные могут отличаться от реальных.
Решение: использовать проверенные PID и калибровку.
Потеря Bluetooth-связи — ELM327 может отключиться. Решение: автоматическое переподключение.
Несовместимость с некоторыми авто — не все поддерживают OBD-II. Решение: проверка протокола при подключении.
Питание — DFPlayer, Arduino требует до 500 мА. Решение: отдельный источник 5V.
Ограничения: Система работает только с OBD-II (машины после 1996 г.).
Требуется Bluetooth Classic (не BLE). Голосовые команды заранее записаны (не генерируются).

   ## Корпус устройства.
  	
Форма: Прямоугольный корпус 120 × 80 × 40 мм — компактный, помещается в бардачок.
Материал: Пластик ABS (3D-печать) — прочный, лёгкий, не проводит ток. Альтернатива: готовый пластиковый бокс (как на фото).
Размещение элементов: Arduino UNO — по центру. HC-05 — справа, антенной наружу. DFPlayer + SD — слева и рядом SD-модуль Micro SD Card Reader. Динамик — на верхней панели, с отверстиями для звука. Кнопка включения — на передней панели. 
Разъём питания — сзади. Крепление: Двусторонний скотч — на панель автомобиля. Магнитное крепление — на металлическую поверхность. Липучка — универсальный вариант. Внешний вид: Матовый чёрный/белый пластик. Логотип «АвтоГолос» на лицевой панели. Индикатор питания (зелёный светодиод). Кнопка вкл, выкл.
Система классификации данных: Передача в облако:  Данные с SD-карты (CSV) синхронизируются с облаком (Яндекс.Диск или Облако.Mail). В будущем — автоматическая отправка через Wi-Fi-модуль.

  ## Работа ИИ-составляющей.
  
Что получает система: С OBD-II через ELM327 система считывает 7 параметров: обороты (RPM), температура ОЖ, скорость, нагрузка, положение дросселя, расход воздуха (MAF), температура воздуха на впуске.
Что анализирует ИИ: Скользящее окно из 5 измерений — хранит последние 5 значений каждого параметра.

Вычисляет скорость изменения (тренд): ΔT/Δt. Сравнивает с порогами и анализирует динамику.
Как принимает решение: Если температура растёт быстрее 2°C/сек → «Внимание! Опасная динамика».
Если обороты растут быстрее 500 об/мин/сек → «Высокие обороты».
Если напряжение падает быстрее 0.3 В/сек → «Низкий заряд батареи».
Какой результат выдаёт:

Голосовое сообщение через DFPlayer.
Запись на SD-карту (CSV).
Отправка в приложение (в разработке). Польза для пользователя: Обычный сканер предупреждает, когда порог уже превышен. Наша система предупреждает за 20–30 секунд до критической ситуации — это и есть ИИ.
